# The Sharps Lab

Mobile-friendly landing page for sports bettors. Features a fun quiz that reveals your "bettor DNA" while collecting research data to build better betting tools.

## 🎯 About

We're building a sports research platform for bettors; tools that organize research to compare matchups and save time. This quiz helps us understand real betting habits in order to build the tools you actually need.

**The Sharps Lab: Where instinct meets intelligence.**

## ✅ Built With

- Vanilla HTML/CSS/JS (no frameworks = blazing fast)
- Google Fonts (Inter)
- Typeform quiz embed
- Mobile-first responsive design
- Optimized for Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/knowo1234/the-sharps-lab)
